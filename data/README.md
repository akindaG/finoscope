# Data policy and source register

Do not commit large datasets, personal information, sensitive data or files whose licence does not permit redistribution.

For every source, record:
- Dataset name and publisher.
- Canonical source URL and access date.
- Licence / terms of use and permitted purposes.
- Version, file names and checksums where appropriate.
- Record count, date range, features and target.
- Known quality issues, missingness and limitations.
- Download instructions or a reproducible acquisition script.
- Whether redistribution in this repository is permitted.

The proposed OFR Financial Stress Index is a candidate for MACROGUARD research. Its exact terms, machine-learning use and commercial reuse must be verified before use. No dataset is approved or included by this initial commit.
